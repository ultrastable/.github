# Contributing

Ultrastable is open: the repositories are public and the Ultrastable License governs use. For pilots, partnerships or questions, email **pilot@ultrastable.io**.

Open an issue first, keep pull requests small, describe what you changed and how you checked it, and never include secrets or private details.

Commit titles follow [Conventional Commits 1.0.0](https://www.conventionalcommits.org/en/v1.0.0/) and releases follow [Semantic Versioning 2.0.0](https://semver.org/). `python3 scripts/repoconform.py --check .` in `ultrastable/seed` reads whether this repository carries the files agents and tools expect.
